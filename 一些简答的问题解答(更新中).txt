1.	Q:如何重新安装环境（如何从CPU环境切换到GPU环境）
	A:
	首先确认你是N卡 然后打开requirements.txt
	把paddleocr改成paddleocr==2.7.3
	再把现在的环境删了 
	conda remove --n mc
	然后重新创建mc环境
	conda create -n mc python=3.10
	之后进入mc环境
	conda activate mc
	安装cudatoolkit和paddle
	conda install paddlepaddle-gpu==2.6.1 cudatoolkit=11.7 -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/Paddle/ -c conda-forge
	再cd到你项目文件夹(例如你的脚本文件夹在c:\mctool的话)
	c:
	cd c:\mctool
	然后再安装gpu依赖
	pip install -r .\requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
